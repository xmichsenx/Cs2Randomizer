# CS2 Randomizer — Crosshair & Loadout

A static, frontend-only web app with two tools for Counter-Strike 2:

- **Crosshair randomizer**: rolls a random crosshair, draws a pixel-accurate preview and gives you a share code you can import in CS2. It also gives the equivalent console commands.
- **Loadout randomizer**: rolls a random buy (primary, pistol, armor, grenades, Zeus / defuse kit) from every CS2 weapon. It respects the side, a budget and the grenade carry limits.

## Crosshair codes

CS2 changed its crosshair share-code format on **30 September 2026** (game version 1.41.8.8). Codes now look like
`CSvbPubOq37zTGqtsPTP5QTrp5CB4xFXiKRLfzJsm49ZRe` ("CS" followed by 44 characters, 32 bytes of data). The old
`CSGO-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx` codes are no longer accepted on import, so this app only produces the new format.

Sizes (thickness, length, gap) are whole pixels authored at a screen height. CS2 rescales them to your resolution.
All 10 styles are supported: Dynamic Cross, Dynamic Circle, Dynamic Cross (Legacy), Static Circle, Static Cross,
Static Cross (Shot Feedback), Dot Only, Dynamic Quad, Static Square and Static Quad.

The encoder is checked against codes generated by CS2 itself (see `tests/`). The byte layout follows
[akiver/csgo-sharecode](https://github.com/akiver/csgo-sharecode/blob/main/doc/code_layout.md).

**Importing in game:** Settings → Crosshair/Scopes → Share or Import → paste the code → Import.

## Weapon pool

All 34 firearms (10 pistols, 7 SMGs, 6 shotguns & machine guns, 7 rifles, 4 snipers), plus Kevlar / Kevlar + Helmet,
all 6 grenade types (max 4 grenades, 2 flashbangs) and the Zeus x27 / Defuse Kit. Side-specific items are only rolled
for their side. You can exclude individual weapons in the app.

## Development

No build step: plain HTML, CSS and ES modules.

```bash
python -m http.server 5317   # then open http://localhost:5317
npm test                     # Node 18+, runs the encoder / loadout tests
```
